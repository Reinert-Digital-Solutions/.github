# Sicherheitsrichtlinie

Sicherheitslücken bitte **nicht** als öffentliches Issue melden.

Meldung per E-Mail an **contact@reinert-digital.de** mit:

- betroffenem Repository und Version bzw. Commit
- Beschreibung und Schritten zur Reproduktion
- möglicher Auswirkung

Wir bestätigen den Eingang innerhalb von 3 Werktagen und melden uns mit einer Einschätzung und einem Zeitplan für die Behebung.
